
# HW3: Building Reproducible Research Workflows with LIGO Open Data
This repository reorganizes the [**LIGO Open Science Center tutorial**](https://github.com/losc-tutorial/LOSC_Event_tutorial)
into a reproducible Python package with automated testing and documentation.  
It was completed as part of the **Fall 2025 STAT 159/259 course**  
at the **University of California, Berkeley**.

---
## Project Overview

This repository demonstrates the full workflow of building a reproducible research project using Git and GitHub.  

Key components include:
- **Modularized code** (`ligotools` package) that can be installed and tested
- **Automated unit tests** using `pytest`
- **Documentation website** built with **MyST Markdown** and deployed via **GitHub Pages**
- **Interactive notebook launch** through the **Binder** badge on this page
- **.gitignore** file ensuring only relevant project files are tracked in the repository

The repository also contains a completed `ai_documentation.txt` file  
that documents the use of AI tools and generated content throughout this assignment.
